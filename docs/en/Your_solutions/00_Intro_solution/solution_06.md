### Step 1: Find the First Derivative

To locate the local maxima or minima, we first need to find the critical points of the function. We do this by taking the first derivative of $f(x)$ with respect to $x$ using the power rule.


$$f(x) = 3x^2 - 12x + 7$$

$$f'(x) = 6x - 12$$

### Step 2: Find the Critical Points

Critical points occur where the first derivative is equal to zero (or is undefined). Set $f'(x)$ to zero and solve for $x$:


$$6x - 12 = 0$$

$$6x = 12$$

$$x = 2$$

This tells us there is a critical point at $x = 2$.

### Step 3: Determine the Nature of the Critical Point

To determine whether this critical point is a local maximum or a local minimum, we can use the Second Derivative Test. We find the second derivative by differentiating $f'(x)$:


$$f''(x) = 6$$

Since the second derivative is a positive constant ($6 > 0$) for all values of $x$, the graph of the function is concave up. A concave up curve means the critical point we found is a **local minimum**. *(Alternatively, you can note that the original function is a parabola opening upwards because the coefficient of $x^2$ is positive).*

## 12. Transformer Currents

A transformer has a primary coil with 1000 turns and a secondary coil with 200 turns. If the primary voltage is $120\text{ V}$ (AC), what is the secondary voltage? If the current in the secondary is $3\text{ A}$, what is the current in the primary?

---

## Solution: Transformer Currents

### Definitions

* $V_p =$ primary voltage (V)
* $V_s =$ secondary voltage (V)
* $I_p =$ primary current (A)
* $I_s =$ secondary current (A)
* $N_p =$ number of turns in the primary coil
* $N_s =$ number of turns in the secondary coil

**Principles for an Ideal Transformer:**

1. **Voltage/Turns Ratio:** $\frac{V_s}{V_p} = \frac{N_s}{N_p}$
2. **Power Conservation:** $V_p I_p = V_s I_s$

---

### Given

* $N_p = 1000$
* $N_s = 200$
* $V_p = 120\text{ V}$
* $I_s = 3\text{ A}$

---

### Step 1: Find the secondary voltage

Using the voltage relation:


$$\frac{V_s}{120} = \frac{200}{1000}$$

$$\frac{V_s}{120} = 0.2$$

$$V_s = 120 \times 0.2 = 24\text{ V}$$

**Secondary voltage:** $\boxed{24\text{ V}}$

---

### Step 2: Find the primary current

Using the power relation:


$$V_p I_p = V_s I_s$$

$$I_p = \frac{V_s I_s}{V_p}$$

$$I_p = \frac{24 \times 3}{120} = \frac{72}{120} = 0.6\text{ A}$$

**Primary current:** $\boxed{0.6\text{ A}}$

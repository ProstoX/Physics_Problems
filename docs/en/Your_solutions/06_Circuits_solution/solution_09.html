Electric Charge and Current Over Time

A visual comparison of charge and current for the same motion in time. The moving points update continuously while a fixed marker highlights the values at t = 3 s.
Charge function
Q(t) = 5t² + 5   coulombs
Current function
I(t) = dQ/dt = 10t   amperes

Charge vs. Time

The curve shows how electric charge changes over time. The gold point marks t = 3 s, and the bright point shows the animated time marker.

Highlighted values at t = 3 s

These values are computed directly from the formulas.

Charge
Q(3) = 50.00 C
Substitute t = 3 into Q(t) = 5t² + 5.
Current
I(3) = 30.00 A
Substitute t = 3 into I(t) = 10t.
The moving marker updates the live time value, while the fixed gold point always remains on the curve at t = 3 s.

Current vs. Time

Since current is the derivative of charge, the current graph is the slope of the charge curve.

Why this works

Current is the rate at which charge changes with time. That means I(t) is the derivative of Q(t). For Q(t) = 5t² + 5, the derivative is I(t) = 10t, which matches the current graph exactly.

1. Non-Traveling Wave: y(x,t) = A * cos(k*x² - ω*t)
Notice how this wave stretches, compresses, and distorts as time progresses. Because the spatial variable 'x' is squared, it cannot be written in the form f(x ± vt). It does not preserve its shape, so it is not a valid traveling wave.
2. Right-Moving Wave: y(x,t) = A * (x - v*t)²
Notice how the parabolic pulse moves smoothly to the right without changing its shape at all. Because it is a function of (x - vt), it represents a valid traveling wave moving in the positive x-direction.
3. Left-Moving Wave: y(x,t) = A * log(|x + v*t|)
Notice how the logarithmic spike moves smoothly to the left without changing its underlying shape. Because it is a function of (x + vt), it represents a valid traveling wave moving in the negative x-direction.
